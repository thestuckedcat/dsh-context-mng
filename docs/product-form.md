# 07 产品形态：上下文观察

版本CTX-PF-1，2026-11-07。状态：产品方向已确认，功能未实现；独立评审状态见根[评审报告](../../docs/design-review-surfaces.md)。

| ID | 最终目标与首版范围 | 状态/来源 |
|---|---|---|
| CTX-PF-01 | 首版在Harness只读观察上下文；手动压缩以详细设计承接、后续增量实现 | 用户集中Q07答复“首版只读观察，手动压缩后续增量” |
| CTX-PF-02 | 原生上下文面板显示来源组成、用量/估算、阶段与限制；本地报告；不改变主模型请求 | 设计决定，落实已确认只读范围 |

用户旅程：当前会话打开“上下文”→看来源组成/阶段→按需展开获准片段→对比估算和provider实报→暂停或导出本地过滤报告。不存在请求观测就显示“尚未观测”，中间waterfall不是最终wire，未知不显示成精确数字。

自动行为为范围内采样、脱敏、分类、估算和刷新；用户手动展开、暂停与导出。关闭/切会话清旧view，不显示迟到响应；停用解除观察而不改会话。登录owner仍需当前项目/会话registry许可；只读面板不取得写权限。

可见产物：来源列表、用量条/估算标签、有限文本预览、本地报告。后置手动omit/摘要仅对合法旧tool结果预览后应用；首版不自动压缩、不写长期记忆、不删会话日志、不发送全文给额外服务。模型API仅后续受控摘要走既有批准Provider。

主形态plugin，不另建分析平台；07可独立于08运行。具体RPC、状态、范围及局部需求ID见[软件设计](software-design.md)，布局/刷新频率为可修改设计默认，不需逐项审批。
